🛒 Description du projet
Nom du projet : E‑Commerce Store

Ce projet est une application web de type boutique en ligne développée avec PHP, HTML/CSS et une base de données SQL.
Il permet aux utilisateurs d’acheter des articles et aux vendeurs de proposer leurs propres produits.

✨ Fonctionnalités principales
Authentification des utilisateurs : inscription et connexion sécurisée.

Catalogue produits : affichage des articles avec images, prix et description.

Panier d’achat : ajout, suppression et gestion des articles avant paiement.

Gestion des vendeurs : possibilité pour un vendeur d’ajouter, modifier ou supprimer ses produits.

Base de données SQL : stockage des informations utilisateurs, produits, commandes et transactions.

Interface responsive : design adapté aux ordinateurs et mobiles grâce à HTML/CSS.

🎯 Objectif
Ce projet vise à fournir une solution simple et efficace pour créer une boutique en ligne.
Il peut servir de base pour un projet académique, un portfolio ou une plateforme réelle de vente.

⚙️ Technologies utilisées
Frontend : HTML5, CSS3

Backend : PHP

Base de données : MySQL
